# 3. Объявления

[← Типы](02-types.md) · [Оглавление](README.md) · [Выражения →](04-expressions.md)

## 3.1 Структура файла

Файл — последовательность объявлений верхнего уровня:

| Объявление | Пример | Раздел |
|---|---|---|
| импорт | `import { puts } from "externs.m"` | [6](06-modules.md) |
| экспорт | `export { colorRed, Color }` | [6](06-modules.md) |
| структура | `type Color { r: UByte, g: UByte, b: UByte }` | [2.6](02-types.md#26-структуры) |
| псевдоним | `type OpFunc = (a: Word, b: Word): Word` | [2.9](02-types.md#29-псевдонимы) |
| перечисление | `enum Cause: UWord { ... }` | [2.7](02-types.md#27-перечисления) |
| глобальная переменная | `let PAGE_SIZE: UWord = 4096` | 3.3 |
| функция | `let add(a: Word, b: Word): Word { ... }` | 3.4 |
| переменная-функция | `let mut onKey(key: UByte): Void { ... }` | 3.8 |
| внешнее объявление | `extern let puts(msg: *UByte): Void` | 3.5 |

`let` вводит и переменные, и функции: после имени идёт `:` — это
переменная, `(` — функция. `let mut` и `(` после имени — переменная типа
функции вместе с телом, на которое она сначала указывает (3.8).

## 3.2 Переменные

```
let x: T = выражение        // неизменяемая
let mut x: T = выражение    // изменяемая
let mut x: T                // изменяемая, без начального значения
```

- Тип пишется всегда. `let x = 5` — ошибка.
- `let` без `mut` нельзя менять после объявления: ни саму переменную, ни
  её поля и элементы. `&x` даёт `*T`, `&mut x` — ошибка.
- `let mut` можно менять целиком и по частям, `&mut x` даёт `*mut T`.
- **`let mut x: T` без `=`** — переменная без начального значения.
  Локальная содержит то, что лежало на стеке: это не UB, а просто
  мусор. Так объявляют буферы, которые всё равно перезапишут. Если
  компилятор видит чтение до первой записи — предупреждение.
- **`let x: T` без `=` и без `mut`** — ошибка: у переменной никогда не
  будет значения.
- Литерал структуры или массива с пропущенными полями или элементами
  заполняет их нулями: `{ .b = 0xFF }`, `{}`, `[1, 2]`, `[]`.
- **`T[]` вместо `T[N]`: длина — по литералу массива**, как в C. Работает
  и для глобальной, и для локальной переменной, с `mut` и без. Длину
  потом даёт `sizeof` ([7.2](07-hardware.md#sizeof-alignof-offsetof)):

  ```
  let bar: StringPtr[] = ["one", "two"]      // StringPtr[2]
  for i: UWord in 0..sizeof(bar) / sizeof(StringPtr) { puts(bar[i]) }
  ```

- **Локальная `let` скалярного типа с константным инициализатором —
  константа** ([4.2](04-expressions.md#42-литералы-и-константные-выражения)):
  её можно использовать как длину массива или метку `case`, а компилятор
  подставляет значение в код. Места в кадре у неё нет, пока не берётся её
  адрес.

  ```
  let n: UWord = 16
  let mut buf: UByte[n * 2]       // UByte[32]
  ```

## 3.3 Глобальные переменные

Переменная, объявленная на верхнем уровне.

- **Инициализатор — только константное выражение**
  ([4.2](04-expressions.md#42-литералы-и-константные-выражения)). До
  `main` никакой код не выполняется. Вызов функции в инициализаторе —
  ошибка. Ссылка на `let mut` — ошибка.
- Адрес другой глобальной переменной или функции — тоже константа: его
  подставляет линкер.

  ```
  let mut current: Color = { .g = 0xFF }
  let currentPtr: *mut Color = &mut current
  let onTick: (): Void = tick
  ```

- **Глобальная `let mut X: T` без `=` — нули**, как в C: она лежит в
  `.bss`, а `.bss` обнуляет загрузчик или `crt0`.
- Глобальная `let` без `mut` и без `=` — ошибка, как и у локальной.

Куда компилятор кладёт глобальные переменные:

| Объявление | Секция |
|---|---|
| `let X: T = константа` | `.rodata`; если адрес нигде не берётся и `X` не экспортируется — значение подставляется в код, символа может не быть |
| `let mut X: T = константа`, хотя бы один байт не ноль | `.data` |
| `let mut X: T = константа`, все байты нули, или без `=` | `.bss` |
| `let mut f(...): R { ... }` | переменная — `.data`, тело — `.text` |

### `align(N)`

```
align(4096) let mut pageDir: UWord[1024]
```

- Выравнивает глобальную переменную на `N` байт. `N` — константное
  выражение, степень двойки, не меньше естественного выравнивания типа.
- У локальной переменной — ошибка: `sp` выровнен только на 8 (ABI,
  «Stack»).
- У функций и типов `align` нет.

Пример: [examples/globals.m](../../examples/globals.m).

## 3.4 Функции

```
let colorMix(a: Color, b: Color): Color {
    let c: Color = { .r = a.r | b.r, .g = a.g | b.g, .b = a.b | b.b }
    return c
}
```

- Тип результата пишется всегда, в том числе `Void`.
- Параметры разделяются запятыми, последняя запятая необязательна. Имена
  параметров уникальны.
- **Параметры неизменяемы**, как `let`. Чтобы менять значение, его
  копируют в `let mut`.
- Параметр типа `T[]` или `mut T[]` — указатель
  ([2.5](02-types.md#25-массивы)).
- Структуры и массивы передаются и возвращаются по значению; как
  именно — решает ABI ([2.11](02-types.md#211-размеры-для-sizeof-и-abi)).
- **`return`**: в функции с результатом `T` — `return выражение` типа
  `T`; в `Void` — `return` без выражения. Если функция с результатом
  может дойти до `}` без `return`, это ошибка
  ([5.10](05-statements.md#510-return)).
- Функцию можно объявить и внутри другой функции, а также записать
  литералом (3.8).
- Рекурсия разрешена.

### Вариативные параметры

```
let sum(initial: Word, args: ...): Word {
    let mut total: Word = initial
    for i: UWord in 0..vaCount(args) total += vaArg(args, i, Word)
    return total
}

let example(): Word { return sum(10, 20, 30) }  // 60
```

- `имя: ...` — именованный пакет оставшихся аргументов. Такой параметр
  бывает только последним и может быть единственным. Дополнительных
  аргументов может быть сколько угодно, в том числе ноль.
- Дополнительные аргументы — скаляры: целые, `Bool`, `Float`, `enum`,
  указатели и функции. Структуры, массивы и `Void` не допускаются;
  передайте адрес массива или структуры явно, если он нужен.
- Целый литерал получает тип `Word`, если помещается, иначе `UWord`.
  Литерал вне диапазона этих типов — ошибка. `null` получает `*Void`.
  Остальные значения сохраняют тип; `Float` остаётся binary32.
- `vaCount(args): UWord` возвращает число дополнительных аргументов.
  `vaArg(args, index, T): T` читает аргумент по индексу `index: UWord`
  начиная с нуля. `T` — скалярный тип. Это чтение представления, а не
  числовое преобразование; `vaArg(args, i, Float)` не преобразует целое
  во `Float`. Соответствие типа и границы проверяет вызываемая функция:
  индекс должен быть меньше `vaCount(args)`, а тип — соответствовать
  переданному значению. Целые допускают чтение тем же представлением
  с другим знаком и сужение до младших битов.
- Пакет неизменяем и живёт до возврата исходного вызова. Его нельзя
  объявить как обычную переменную, поле, результат или псевдоним типа.
  Передача пакета **единственным дополнительным аргументом** перенаправляет
  его без копирования значений: `sum(0, args)`. Смешивать пакет с другими
  дополнительными аргументами нельзя.
- Вариативность — часть типа функции:
  `(initial: Word, args: ...): Word` отличается от `(initial: Word): Word`.
  Поддерживаются вложенные функции, литералы и переменные-функции.
- Вариативные функции M используют пакет из адреса данных и длины
  ([ABI](../../../docs/ABI.md#m-variadic-arguments)); это отдельное соглашение
  от C `...` и `va_list`. Вариативный `extern` должен соблюдать соглашение M.

### `main`

```
let main(argc: UWord, argv: *UByte[]): Word { ... }
```

- `main` — обычная функция, которую вызывает `crt0` рантайма. Её
  результат `crt0` передаёт в `exit`.
- **`main` экспортируется сама**, `export { main }` писать не нужно (можно
  — ничего не изменится). Это единственное исключение из явного
  экспорта ([6.2](06-modules.md#62-export)).
- Сигнатуру задаёт рантайм, а не язык: процессу — `argc`/`argv`, как
  выше; boot-образу — своя ([7.7](07-hardware.md#77-рантайм)).

## 3.5 `extern`

Объявляет функцию или переменную, которая определена в другом месте: в
ассемблере, в C, в скрипте линкера.

```
extern let puts(msg: *UByte): Void      // функция
extern let __bss_start: UByte           // символ линкера
extern let mut ticks: UWord             // переменная, которую можно менять
```

- Имя символа ELF равно имени в объявлении. Отдельного атрибута для
  имени символа нет; при импорте имя можно поменять через `as`
  ([6.3](06-modules.md#63-import)).
- У `extern`-функции нет тела, у `extern`-переменной нет инициализатора.
- `extern` с `args: ...` использует вариативное соглашение M (3.4).
- **Символ линкера** объявляется как переменная любого типа, а
  используется только его адрес: `&__bss_start as UWord`.
- `extern`-объявление можно экспортировать: импортирующий файл получит
  объявление, символ при этом определяет кто-то третий
  ([6.2](06-modules.md#62-export)).

## 3.6 Объявления типов

`type`, `packed type`, `type ... =` и `enum` описаны в
[разделе 2](02-types.md). Все они — только на верхнем уровне.

## 3.7 Область видимости и порядок

- **Верхний уровень — в любом порядке.** Функция может вызвать функцию
  ниже, поле может иметь тип, объявленный ниже, константа может
  ссылаться на константу ниже. Предварительных объявлений нет.
- Ошибки на верхнем уровне:
  - цикл в инициализаторах (`let A: UWord = B`, `let B: UWord = A`);
  - структура, которая содержит саму себя по значению;
  - псевдоним, который ссылается на себя.
- **Имена верхнего уровня в файле уникальны**, вместе с импортированными:
  импортировать `mix` и объявить свою `mix` — ошибка.
- **Внутри функции — по порядку:** локальная переменная видна от своего
  объявления до конца блока `{ }`, в котором объявлена.
- Каждый блок, тело цикла и `case`-блок — своя область видимости.
  Переменная `for` видна только в теле цикла.
- **Затенение — как в C.** Имя во вложенном блоке скрывает такое же имя
  снаружи до конца блока: локальную переменную, параметр, вложенную
  функцию или имя верхнего уровня (глобальную переменную, функцию, тип,
  импортированное имя). В инициализаторе ещё видно внешнее имя:

  ```
  let size: UWord = 4
  if wide {
      let size: UWord = size * 2  // справа — внешняя size; эта — до '}'
      use(size)                   // 8
  }
  use(size)                       // 4
  ```

- **В одном блоке имя одно:** два одинаковых имени в одном блоке —
  ошибка. Параметры и тело функции — один блок, как в C: локальную с
  именем параметра можно объявить только во вложенном блоке. После конца
  блока имя свободно:

  ```
  for i: UWord in 0..n { ... }
  for i: UWord in 0..m { ... }    // можно: первая i уже не видна
  ```

- Затенение локальной переменной, параметра или вложенной функции —
  **предупреждение** (8.1): так легко перепутать две переменные.
  Затенение имени верхнего уровня — без предупреждения.
- Затенить можно и тип: до конца блока имя — переменная, и как тип его
  не написать (`let c: Color` — ошибка), а `sizeof(Color)` — размер
  переменной ([7.2](07-hardware.md#sizeof-alignof-offsetof)), как в C.
- **Вложенная функция и литерал** не видят локальных переменных и
  параметров внешней функции (3.8), поэтому их параметры и переменные
  могут называться так же, без предупреждения. Если внешняя функция
  затенила глобальное имя, внутри видно глобальное.

Пример: [examples/order.m](../../examples/order.m).

## 3.8 Вложенные функции и литералы

Функцию можно объявить внутри другой функции тремя способами:

```
let main(argc: UWord, argv: *UByte[]): Word {
    let n: UWord = 10

    // вложенная функция
    let square(n: UWord): UWord {   // можно: внешняя n здесь не видна
        return n * n
    }

    // переменная-функция: let mut func: (): Void и тело, на которое она указывает
    let mut func(): Void {
        puts("foo\n")
    }
    func()                          // "foo"
    func = bar
    func()                          // "bar"

    // литерал функции
    func = (): Void { puts("baz\n") }
    onStack((): Void {
        bootDisk(floppy, "floppy")
    }, BOOT_STACK_TOP)

    return square(n) as Word
}
```

### Захвата нет

**Вложенная функция и литерал не видят локальных переменных и
параметров внешней функции.** Внутри видно:

- свои параметры и локальные переменные;
- всё верхнего уровня: глобальные переменные, функции, типы, `enum`,
  импортированные имена — даже если внешняя функция затенила имя своей
  локальной (3.7);
- вложенные функции (без `mut`), объявленные выше в объемлющих блоках
  внешних функций, и сама функция — для рекурсии. Это не захват: им не
  нужны данные внешней функции.

Не видно: локальных переменных и параметров внешних функций, в том числе
переменных-функций `let mut` (это тоже локальные переменные).

```
let mut count: UWord = 0
let bump(): Void {
    count++         // ошибка: 'count' is a local of 'main': a nested function can't capture it
}
```

Поэтому значение остаётся простым указателем на код
([2.8](02-types.md#28-тип-функции)): его можно передать в
`extern`-функцию, положить в `IVEC` или в таблицу обработчиков. Если
функции нужны данные вызывающего, их передают параметром — указателем
или `*Void`-контекстом ([2.4](02-types.md#void)).

Вложенная функция в рантайме ничего не стоит: это обычная функция, имя
которой видно только внутри объемлющего блока.

### Вложенная функция

```
let имя(параметры): R { тело }
```

- Синтаксис и правила — как у функции верхнего уровня (3.4).
- **Имя видно от объявления до конца блока**, как имя переменной (3.7).
  Подъёма нет: вызвать вложенную функцию выше её объявления нельзя, и две
  вложенные функции не могут вызывать друг друга. Для этого функции
  выносят на верхний уровень.
- Внутри своего тела имя видно: рекурсия разрешена.
- Имя — локальное имя внешней функции: оно не может совпадать с другими
  видимыми там именами (3.7).
- Это функция, а не переменная: присвоить ей нельзя, `&` у неё не
  берётся (`&twice` — ошибка), вызов — прямой.
- `return`, `break` и `continue` в теле относятся к самой вложенной
  функции: `break` не выходит из цикла внешней.
- Вложенность — любой глубины.
- Экспортировать вложенную функцию нельзя: `export` — только для имён
  верхнего уровня.
- Перед вложенной функцией можно писать `///`.

### Переменная-функция: `let mut`

```
let mut имя(параметры): R { тело }
```

То же, что

```
let имя_тела(параметры): R { тело }      // имя_тела нигде не видно
let mut имя: (параметры): R = имя_тела
```

- `имя` — **изменяемая переменная** типа функции: её можно вызвать,
  присвоить ей другую функцию или `null`, взять `&имя` и `&mut имя`.
  Вызов — косвенный, через текущее значение.
- **Внутри функции** это локальная переменная. Её тело — вложенная
  функция без имени, поэтому `имя` в теле не видно: это локальное имя
  внешней функции, а захвата нет. Рекурсии у неё нет.
- **На верхнем уровне** это глобальная переменная в `.data`, которая
  сначала указывает на тело. Глобальные имена видны всегда, поэтому
  `имя(...)` в теле вызывает **текущее** значение переменной: после
  подмены — уже другую функцию. Экспортируется она как любая глобальная
  переменная.

  ```
  let mut onKey(key: UByte): Void {   // обработчик по умолчанию
      puts("unhandled key\n")
  }

  let main(argc: UWord, argv: *UByte[]): Word {
      onKey(0x41)                     // "unhandled key"
      onKey = myKeyHandler
      onKey(0x41)                     // myKeyHandler
      return 0
  }
  ```

- Если переменной ни разу не присвоили другое значение, это
  предупреждение, как у любой `let mut`: хватило бы `let`.
- `extern let mut имя(...)` без тела нет: внешнюю переменную типа функции
  объявляют как `extern let mut имя: (параметры): R`.

### Литерал функции

```
(параметры): R { тело }
```

- Это выражение: тип функции, к которому дописано тело. Тип литерала —
  записанный в нём тип функции; тип результата пишется всегда, вывода
  типов нет.
- Литерал можно написать везде, где нужно значение типа функции:
  инициализатор, присваивание, аргумент, `return`, элемент литерала
  массива или поле литерала структуры.
- Внутри — те же правила, что у вложенной функции, но имени нет, поэтому
  нет и рекурсии.
- **Каждый литерал — отдельная функция.** Два литерала с одинаковым
  текстом — разные функции и по `==` не равны.
- **Адрес литерала — константа**, как адрес функции верхнего уровня
  ([4.2](04-expressions.md#42-литералы-и-константные-выражения)). Поэтому
  литерал можно писать и вне функций — в инициализаторе глобальной
  переменной:

  ```
  let handlers: Handler[2] = [
      (code: UWord): Void { puts("zero\n") },
      onOne,
  ]
  ```

- `(` в начале выражения, за которой идёт `)` или `имя :`, начинает
  литерал функции, иначе — выражение в скобках. Это то же правило, что
  отличает тип функции от скобок в типе ([9](09-grammar.md)).
- В условии `if`, `while`, `for` и в выражении `switch` литерал функции
  пишется только в скобках: `{` там начинает тело.
- Литерал в отдельной строке — ошибка, как любое выражение, которое не
  вызов (5.1).

Пример: [examples/nested.m](../../examples/nested.m).
