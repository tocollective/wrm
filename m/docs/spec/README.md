# Язык M — спецификация

Версия 0.1, 2026-10-02.

M — системный язык без рантайма для машины WRM.081632: 32-битный
процессор, ABI из [docs/ABI.md](../../../docs/ABI.md), выход компилятора —
ассемблер для `tools/asm.py`. По духу это C с синтаксисом в стиле
Swift/Zig: типы после имени, `let`/`let mut`, никаких неявных приведений,
явный экспорт, прямой доступ к железу.

```
import { puts } from "externs.m"

type Color {
    r: UByte,
    g: UByte,
    b: UByte,
}

let colorMix(a: Color, b: Color): Color {
    let c: Color = { .r = a.r +| b.r, .g = a.g +| b.g, .b = a.b +| b.b }
    return c
}

let main(argc: UWord, argv: *UByte[]): Word {
    for i: UWord in 0..argc puts(argv[i])
    return 0
}
```

## Условности

- **Ошибка** — компилятор отклоняет программу. **Предупреждение** —
  сообщает, но компилирует.
- «INSTRUCTIONS, …», «ABI, …», «SPECIFICATION, …» — разделы
  [docs/INSTRUCTIONS.md](../../../docs/INSTRUCTIONS.md),
  [docs/ABI.md](../../../docs/ABI.md),
  [docs/SPECIFICATION.md](../../../docs/SPECIFICATION.md).
- Примеры кода в спецификации — фрагменты. Полные программы — в
  [examples/](../../examples/): **каждый файл там должен компилироваться**
  компилятором, который следует этой спецификации. Строки, которые не
  должны компилироваться, закомментированы и помечены
  `Compile error`.

## Откуда взялись правила

Почему выбрано именно так и какие были варианты — в
[REPORT.md](../REPORT.md): там каждое решение записано вместе с разбором.

Следующие правила появились при составлении спецификации, чтобы она
была полной, и потом были приняты:

| Правило | Раздел |
|---|---|
| Параметры функции неизменяемы: `&` взять можно, `&mut` — нет | [3.4](03-declarations.md#34-функции) |
| Затенения нет: локальное имя не может совпадать с видимым именем, параметром или именем верхнего уровня файла | [3.7](03-declarations.md#37-область-видимости-и-порядок) |
| `extern let mut` — внешняя изменяемая переменная | [3.5](03-declarations.md#35-extern) |
| Структура — хотя бы одно поле; массив — хотя бы один элемент | [2.5](02-types.md#25-массивы), [2.6](02-types.md#26-структуры) |
| Структуры и массивы не сравниваются `==`; указатели — только `==`/`!=` | [4.9](04-expressions.md#49-сравнения-и-логические-операторы) |
| `enum` сравнивается `<`/`>`, но арифметики и `++` у него нет | [2.7](02-types.md#27-перечисления) |
| Целое в `Bool` через `as` нельзя, только `x != 0` | [4.6](04-expressions.md#46-приведение-as) |
| Оператором может быть только вызов, присваивание, `++`/`--`; `x + 1` в строке — ошибка | [5.1](05-statements.md#51-операторы-и-их-границы) |
| Нет `+\|=` и других составных присваиваний с насыщением; `++`/`--` только постфиксные | [5.3](05-statements.md#53-присваивание) |
| В `Void`-функции `return` никогда не берёт выражение, в остальных — всегда | [5.10](05-statements.md#510-return) |
| Проверка «функция дошла до `}` без `return`» — по операторам тела (`return`, `while true` без `break`, `if`/`else`), без анализа значений | [5.10](05-statements.md#510-return) |
| В условии `if`/`while`/`for`/`switch` литерал структуры без скобок нельзя | [9](09-grammar.md) |
| Тип результата в типе функции — весь тип после `:`; массив функций — со скобками или через псевдоним | [2.8](02-types.md#28-тип-функции) |
| Реэкспорта нет: экспорт импортированного имени — ошибка | [6.2](06-modules.md#62-export) |
| Циклический импорт разрешён | [6.3](06-modules.md#63-import) |
| У `Float`-литерала нет экспоненты; префиксы `0x`/`0b` — строчные | [1.5](01-lexical.md#15-числовые-литералы) |
| Адрес встроенной функции взять нельзя | [7.2](07-hardware.md#72-встроенные-функции) |
| `syscall`: аргументы — `Word`, `UWord` или указатели, литералы — `UWord` | [7.2](07-hardware.md#72-встроенные-функции) |
| `atomicAdd` — только `Word`/`UWord`, не указатели | [7.5](07-hardware.md#75-атомики) |
| `asm` не должен менять `sp` и callee-saved регистры | [7.4](07-hardware.md#74-asm) |
| Вложенные функции и литералы функций — без захвата: внешние локальные внутри не видны, поэтому их имена можно повторять | [3.8](03-declarations.md#38-вложенные-функции-и-литералы) |
| `let mut f(...) { }` — переменная типа функции вместе с телом, в том числе на верхнем уровне | [3.8](03-declarations.md#38-вложенные-функции-и-литералы) |
| `*Void`: любой указатель становится им неявно, обратно — только `as`; разыменовать нельзя. Функция ↔ `*Void` — через `as` | [2.4](02-types.md#void), [4.6](04-expressions.md#46-приведение-as) |

## Чего нет и не будет в первой версии

Сознательно нет: методов и ООП, вывода типов, неявных приведений (кроме
пяти), 64-битных типов, `Never`, меток у `break`/`continue`,
`section`, битовых полей, срезов, `import *`.

Отложено и может появиться позже, не ломая код: `defer`, обработка
ошибок, tagged union, обобщённые типы, вычисления при компиляции
([REPORT.md, 5.2](../REPORT.md)).
