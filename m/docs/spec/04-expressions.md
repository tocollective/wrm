# 4. Выражения

[← Объявления](03-declarations.md) · [Оглавление](README.md) · [Операторы →](05-statements.md)

## 4.1 Приоритеты

От сильного к слабому:

| Уровень | Операторы | Ассоциативность |
|---|---|---|
| 1 | вызов `f(...)`, индекс `a[i]`, поле `a.b` | слева |
| 2 | унарные `-`, `!`, `~`, `*`, `&`, `&mut` | справа |
| 3 | `as` | слева |
| 4 | `*`, `/`, `%`, `*\|` | слева |
| 5 | `+`, `-`, `+\|`, `-\|` | слева |
| 6 | `<<`, `>>` | слева |
| 7 | `&` | слева |
| 8 | `^` | слева |
| 9 | `\|` | слева |
| 10 | `==`, `!=`, `<`, `<=`, `>`, `>=` | нет |
| 11 | `&&` | слева |
| 12 | `\|\|` | слева |

- **`&`, `|`, `^` сильнее сравнений**, в отличие от C:
  `x & MASK == 0` — это `(x & MASK) == 0`.
- **`as` сильнее арифметики:** `a + b as UWord` — это
  `a + (b as UWord)`, `-x as UWord` — `(-x) as UWord`.
- **Сравнения не связываются в цепочку:** `a < b < c` — ошибка, нужно
  `a < b && b < c`.
- Диапазоны `..` и `...` — не выражения, они бывают только в `for`
  ([5.7](05-statements.md#57-for)).
- Присваивание, `+=` и прочие, `++`, `--` — операторы, а не выражения
  ([5.3](05-statements.md#53-присваивание)).

Пример: [examples/expressions.m](../../examples/expressions.m).

## 4.2 Литералы и константные выражения

### Тип литерала

У целого литерала нет своего типа, пока его не задаст контекст:

- тип переменной в `let`, тип параметра при вызове, тип результата в
  `return`;
- тип другого операнда бинарного оператора: в `a + 1` у `a: UByte`
  литерал `1` — `UByte`;
- тип поля или элемента в литерале структуры или массива;
- тип переменной `for` для границ и шага диапазона;
- целевой тип в `as`: `7 as Direction`.

Литерал, которому контекст не задал тип, — ошибка. Поскольку тип
каждой переменной пишется явно, это бывает редко: например, `1 << 40`
без переменной слева.

`'a'` — всегда `UByte`; `1.5` — всегда `Float`; `"..."` — всегда
`*UByte`; `true`/`false` — `Bool`; `null` — тот указатель, которого
ждёт контекст.

### Константное выражение

Значение известно при компиляции, если выражение составлено только из:

- литералов;
- глобальных `let`-переменных (без `mut`) с константным
  инициализатором;
- локальных `let`-переменных (без `mut`) скалярного типа с константным
  инициализатором: их нельзя изменить, поэтому значение всегда то,
  которым их инициализировали (3.2);
- элементов `enum`;
- `sizeof`, `alignof`, `offsetof`;
- арифметических, побитовых операторов, сдвигов, сравнений, логических
  операторов и `as` над всем перечисленным;
- литералов структур и массивов из констант;
- адресов глобальных переменных, функций и литералов функций (их
  подставит линкер; такие константы годятся только для инициализации, а
  не для размеров массивов и меток `case`).

Где константа обязательна: инициализатор глобальной переменной, длина
массива `T[N]`, значение элемента `enum`, метка `case`, шаг `by`,
аргумент `N` у `align(N)`, номер регистра у `mfcr`/`mtcr`.

**Константное выражение из одних литералов считается точно**, с
произвольной точностью, и только результат приводится к типу контекста.
Если он не влезает — ошибка:

```
let a: UByte = 300 - 100        // 200: промежуточные 300 — можно
let b: UByte = 300              // ошибка
let c: UByte = -1               // ошибка
let d: UByte = 0x10 *| 0x10     // ошибка: 256; насыщение — только в рантайме
```

Если в константном выражении участвует типизированное значение
(`let`-константа, элемент `enum`), операции идут в его типе по
обычным правилам: с переносом (4.7).

## 4.3 Первичные выражения

- литерал (1.5–1.7);
- имя переменной, параметра, функции, элемента `enum` (`Cause.Syscall`);
- выражение в скобках `( ... )`;
- литерал структуры `{ .r = 1, .g = 2 }` и массива `[1, 2, 3]` — только
  там, где тип известен из контекста (4.10);
- литерал функции `(x: Word): Word { return x * 2 }`
  ([3.8](03-declarations.md#38-вложенные-функции-и-литералы));
- вызов встроенной функции ([7.2](07-hardware.md#72-встроенные-функции)).

## 4.4 Постфиксные операторы

### Вызов

```
f(a, b)
handlers[code](code)
```

- Вызвать можно функцию по имени или значение типа функции.
- Число и типы аргументов должны совпадать с параметрами (с учётом
  неявных приведений, [2.10](02-types.md#210-совместимость-и-неявные-приведения)).
  Для функции с последним `args: ...` это правило относится к фиксированным
  параметрам; дополнительные скалярные аргументы образуют пакет
  ([3.4](03-declarations.md#вариативные-параметры)).
- **Аргументы вычисляются слева направо**, потом выполняется вызов.

### Индекс

`a[i]` — у массива `T[N]` и у указателя `*T`/`*mut T` (в том числе
параметра `T[]`), кроме `*Void`.

- Индекс — **любой беззнаковый** целый тип: `UByte`, `UHalf`, `UWord`.
  Знаковый индекс — ошибка, нужен `as`.
- Проверки границ нет.
- `p[i]` у указателя — элемент по адресу `p + i × sizeof(T)`. Записывать
  в него можно, если `p: *mut T`.
- `a[i]` у массива-переменной можно менять, если переменная `let mut`.

### Поле

`s.f` — поле структуры.

- У указателя на структуру — та же точка: `p.f` значит `(*p).f`. У
  `*Void` полей нет: сначала `as`.
  Разыменовывается **ровно один уровень**: у `pp: **T` нужно `(*pp).f`.
  Стрелки `->` нет.
- Писать `p.f = ...` можно, только если `p: *mut T`. Писать `s.f = ...` —
  только если `s` — `let mut`.
- `volatile` проходит через `.`: поле, прочитанное через
  `*volatile T`, — обращение к устройству
  ([7.1](07-hardware.md#71-volatile-и-mmio)).

## 4.5 Унарные операторы

| Оператор | Операнд | Результат |
|---|---|---|
| `-x` | целое или `Float` | то же; у целых — с переносом: `-(-128)` у `Byte` = `-128`, `-1` у `UByte` = `0xFF` |
| `~x` | целое | побитовое «не» |
| `!x` | `Bool` | логическое «не» |
| `*p` | указатель, кроме `*Void` | значение по адресу; писать `*p = ...` можно у `*mut T` |
| `&x` | переменная, поле, элемент, `*p` | `*T` |
| `&mut x` | то же, но изменяемое | `*mut T` |

- `&mut x` можно взять у `let mut`-переменной, у поля или элемента
  такой переменной и у `*p`, `p.f`, `p[i]` при `p: *mut T`.
- `&` и `&mut` нельзя взять у литерала, результата вызова и другого
  временного значения. У параметра можно взять `&`, но не `&mut`:
  параметр неизменяем.
- `&` у функции не пишется: имя функции уже указатель. `&foo` — ошибка,
  в том числе у вложенной функции и у литерала. У переменной-функции
  `let mut f(...)` `&f` и `&mut f` берутся, как у любой переменной
  ([3.8](03-declarations.md#38-вложенные-функции-и-литералы)).
- `&` у поля, прочитанного через `volatile`-указатель, даёт
  `volatile`-указатель: `&uart.status` — `*volatile UWord`.
- Адрес невыровненного поля `packed`-структуры — ошибка
  ([2.6](02-types.md#26-структуры)).

## 4.6 Приведение `as`

`x as T` — единственный способ сменить тип (кроме пяти неявных
приведений из [2.10](02-types.md#210-совместимость-и-неявные-приведения)).

| Откуда | Куда | Что происходит |
|---|---|---|
| целое | целое шире | расширение: знаковое — по знаку, беззнаковое — нулями (по типу **источника**) |
| целое | целое уже или той же ширины | младшие биты; знак — по типу результата |
| целое | `Float` | `ITOF`/`UTOF`, округление к ближайшему |
| `Float` | целое | `FTOI`/`FTOU`: к нулю, **с насыщением**; NaN — максимум типа (не UB) |
| `Bool` | целое | `false` = 0, `true` = 1 |
| целое | `enum` / `enum` | целое | как целое ↔ базовый тип; не проверяется |
| указатель | `UWord`, `Word` | адрес как число |
| `UWord`, `Word` | указатель | число как адрес: `0xFD00_2000 as *volatile mut UartRegs` |
| указатель | указатель | тот же адрес, любой другой тип указуемого, можно добавить или снять `mut` и `volatile` |
| функция | `UWord` | адрес кода |
| функция | `*Void`, `*mut Void` | адрес кода как указатель |
| `*Void`, `*mut Void` | функция | указатель как адрес кода; не проверяется |

Нельзя: целое в `Bool` (нужно `x != 0`), `as` между структурами,
массивами и функциями разных типов, `as` у `Void`.

## 4.7 Арифметика

`+`, `-`, `*`, `/`, `%`, `+|`, `-|`, `*|`.

- **Оба операнда одного типа**, результат — того же типа. Повышений, как
  в C, нет: `UByte + UByte` — `UByte`, `UByte + UWord` — ошибка, нужно
  `(a as UWord) + b`.
- `+`, `-`, `*` **всегда с переносом** по модулю 2ⁿ, у знаковых тоже:
  `0xFF + 1` у `UByte` — `0x00`, `127 + 1` у `Byte` — `-128`. Ловушек при
  переполнении нет.
- `+|`, `-|`, `*|` — **с насыщением**: результат прижимается к минимуму
  или максимуму типа. `0xFF +| 1` у `UByte` — `0xFF`, `0 -| 1` — `0`,
  `-128 -| 1` у `Byte` — `-128`. Только для целых.
- **Деление на ноль не ловушка** (так делает процессор): `x / 0` — все
  единицы в типе (`0xFF` у `UByte`, `0xFFFFFFFF` у `UWord`, `-1` у
  знаковых), `x % 0` — `x`.
- `MIN / -1` у знаковых — `MIN`, `MIN % -1` — `0`.
- `/` округляет к нулю, знак `%` совпадает со знаком делимого, как в C.
- У `Float`: `+`, `-`, `*`, `/` по IEEE 754 без ловушек. `%`, `+|`, `-|`,
  `*|` у `Float` нет.

Цена переноса у 8- и 16-битных типов — маскирование после операции
(`ANDI`, у знаковых `SHLI` + `SARI`); у `Word`/`UWord` — ничего.

## 4.8 Побитовые операторы и сдвиги

- `&`, `|`, `^`, `~` — только у целых; оба операнда одного типа.
- `x << n`, `x >> n`:
  - `x` — целое, результат — тип `x`;
  - `n` — любой беззнаковый целый тип, не обязательно тот же, что у `x`;
  - значение сдвигается как 32-битное, от `n` берутся младшие 5 бит,
    результат обрезается до типа `x`. Поэтому `x << 33` == `x << 1`, а у
    `UByte` `0x81 << 1` — `0x02`, `x << 8` и `x >> 8` — `0`;
  - `>>` у знаковых — арифметический, у беззнаковых — логический.

## 4.9 Сравнения и логические операторы

- `==`, `!=` — у целых, `Float`, `Bool`, `enum`, указателей и функций.
  Оба операнда одного типа (указатель можно сравнить с `null`).
- `<`, `<=`, `>`, `>=` — у целых, `Float` и `enum`. Указатели упорядочить
  нельзя: сначала `as UWord`.
- Структуры и массивы `==` не сравниваются.
- Результат — `Bool`.
- `Float`: NaN не равен ничему, даже себе; `-0.0 == 0.0`.
- `&&`, `||` — только `Bool`, **с коротким замыканием**: правый операнд
  вычисляется, только если от него зависит результат.

## 4.10 Литералы структур и массивов

```
let c: Color = { .r = 0xFF, .b = 0x80 }
let p: Point[2] = [{ .x = 1 }, { .y = 2 }]
```

- Литерал без имени типа; тип берётся из контекста: тип переменной,
  параметра, результата, поля, элемента, `*p = ...`. Без контекста —
  ошибка.
- В литерале структуры поля называются через `.имя = значение`, в любом
  порядке, каждое не больше одного раза. Незнакомое поле — ошибка.
- Не названные поля и не указанные элементы — нули: `{}` и `[]` — всё
  нули.
- Элементов массива больше `N` — ошибка.
- Запятые обязательны между элементами, последняя — необязательна.
- Значения вычисляются слева направо.

## 4.11 Порядок вычисления

- Аргументы вызова — слева направо.
- Операнды бинарных операторов — слева направо.
- `&&`, `||` — правый операнд может не вычисляться.
- В присваивании сначала вычисляется адрес слева, потом значение справа.
